# MOVIMENTAMENTE — estrutura organizada

Projeto reorganizado tomando como referência a estrutura do Cultiva+.

## Estrutura

- `index.html` — aplicação principal.
- `assets/shared.css` — todo o CSS que estava dentro do HTML original.
- `assets/app.js` — todo o JavaScript que estava dentro do HTML original.
- `assets/img/movimentamente-logo.jpg` — logo extraída do HTML.
- Pastas de módulos (`inicio`, `sobre`, `movimento`, `saude-mental`, `sono`, `cidadania`, `estudante`, `pesquisa`, `biblioteca`, `contato`, `quiz`, `feedback`, `atividades`, `videos`, `professor`) — seguem o padrão de organização do Cultiva+, com `index.html`, `index.css` e `index.js`.

## Como executar

Abra `index.html` no navegador ou use o Live Server do VS Code.

## Observação

A lógica e o conteúdo do projeto original foram preservados. A principal mudança desta versão é a separação dos arquivos de HTML, CSS e JavaScript e a organização por módulos.
